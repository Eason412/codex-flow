# 面板、状态行与提醒

用户问到面板，或要改 mod 时读。

## 打开与收起

输入框上方的任务面板和提醒由 `mod/` 提供，通过 `~/.claude/settings.json` 的 `CLAUDE_CODE_PLUGIN_DIRS` 加载到各会话；安装前已开的会话要重开才加载。之后改了 mod，终端会话保存后自动换上新代码；桌面会话默认不换，要重开会话，或在同一个 `env` 里加 `"CLAUDE_CODE_PLUGIN_DIR_WATCH": "1"` 让桌面会话也跟着更新。flow 和 run.sh 单个任务开始时自动打开面板。按 q 随时可以收起：有任务在跑时键写「收起」，任务照常运行，失联提醒照常进对话，并提示用 `/flow` 重新打开；全部结束后写「关闭」。自动打开的面板在最后一个运行结束或发现失联满 30 秒后收起。`/flow` 只负责打开；面板已自动打开时再输 `/flow`，会转为手动打开，之后不自动收起。

自动打开按 runId 和 startedAt 区分每轮：关闭后同一轮不再弹出，续跑同一 runId 的新一轮会重新打开。正在看任务时新任务开始，保留当前选择，把新运行加入列表。列表保留本次面板打开后出现过的已结束运行（通常最多五个，正在看的另行保留），关掉面板时清空这部分保留记录。

面板只显示本进程用过的会话 ID 所派出的运行；`/clear` 换会话 ID 后，旧会话还在跑的任务仍保留、仍提醒。这组 ID 保存在宿主状态中，插件热重载不会丢失；其他会话的运行不显示。

右上角的 `[-]` 是 Claude Code 自带的折叠，折叠后只剩一行「▸ plugin panel hidden」。插件不能解除折叠，点那一行或按 ctrl+x ctrl+a 展开。看子代理对话或填写问卷时，面板会让出位置。

## 终端版面

顶部第一行显示运行名；多个运行时显示「Codex · N 个运行」。统计合计列出的运行，显示完成数/agent 总数、token 和耗时。第二行显示所选 agent 的任务说明；单发 agent 显示自己的说明。没有对应说明时留空。

下面分两栏：只有一个运行时左栏列阶段；多个运行时左栏列运行，选中 flow 的多个阶段缩进列在它下面。右栏列所选阶段的 agent，显示模型、effort、状态与耗时。运行中的 flow 用紫色星形，运行中的阶段用蓝色星形，agent 用蓝色点阵；Fast 在模型前标暗灰 `⚡`。状态文字来自运行记录，可显示改文件次数、验收中、验收通过条数或失败原因。依赖允许几个阶段同时开跑时，各阶段都显示运行标记，默认选第一个运行中的阶段。

两栏正文最多四行，agent 详情最多十二行；超出时各列按窗口显示，下边线放「1–4 of N」和 ↑/↓ 翻页按钮。光标在窗口内移动时窗口不动，越过边界时翻一项并落到新露出的条目。翻页提示放不下或边线未画时，仍可沿边界直接翻页。窄终端优先保留停止（x）和返回（b），必要时把「停止整个 flow」缩为「停止」、省提示，或把按钮放在整条下边线上。

ctrl+x tab 进入面板操作，↑/↓ 选择，Enter 从阶段进入 agent 或打开详情，b 返回。左栏按 x 停选中的整个运行，右栏或详情按 x 停所选 agent。详情左栏可切换 agent，右栏显示任务说明、过程累计数、最近几步，以及结果或错误；正文超出高度时截断并提示剩余行数。运行中的 flow agent 有插话框，验收中、Codex 本轮已结束、已完成或单发 agent 没有。

空间不足时依次省顶部第二行、框线和底部按钮；只剩一行时只显示名字和统计。可收起 Claude Code 的任务清单（ctrl+t）或清空输入框草稿来恢复空间。

## 桌面竖排版面

桌面等非终端端有 Svg 组件时使用竖排版面，不画字符框线。顶部一行显示粗体名字和 agent 总数、token、耗时。多个运行时先显示「Codex · N 个任务」列表，每个运行一行，标 flow 或 agent；进入一个运行后可按 b 返回列表。

flow 页面把阶段竖排列出，当前展开阶段带淡底，缩进列出它的 agent。阶段右侧用小方块表示各 agent 的状态；agent 完成为灰色勾，运行中为呼吸蓝块，失败为红块，等待为空心框。模型与 effort 用暗灰，Fast 在模型后显示小闪电。失败原因接在模型后面，耗时靠右，复用上次结果的 agent 不显示旧耗时。

阶段和展开的 agent 共用可用行数，各自有翻页窗口，翻页提示和按钮在最下一行。agent 没有分到行数时不建它的窗口、不显示 agent 翻页提示，也不会请求聚焦不可见的 agent。flow 页面按 x 停整个 flow；进入 agent 详情后按 x 只停它。多个运行的列表里没有停止按钮，要先进入某个运行。

agent 详情显示一行标题、缩进任务说明；运行中只显示最近一步的一行，验收中改显示验收说明。结束后显示结果前几行（最多四行，超出加省略号）和「完整结果由 Claude 在对话里汇报」，失败显示错误。单发 agent 页面直接显示自己的模型、说明和进展或结果。桌面详情没有插话框和过程计数。

## 提醒与调试

- 任务每跑满一个阈值（默认 900 秒，`CODEX_FLOW_ALERT_AFTER` 或运行记录的 `alertAfter` 调整），只在界面弹一次 toast，不往对话发消息。时长提醒按运行轮次、任务和阈值次数去重；续跑后重新计。
- 唯一进对话的提醒是执行器进程已退出、state 仍写着 running（面板记为 lost）。每轮只发一次，同一运行的任务合在一条里，附运行目录和各任务日志。主对话忙时等空闲重新检查，已结束的不补发。收到后读日志向用户汇报，不自动重跑。
- `ps` 无法查询进程时按仍活着处理，避免误报失联；查询表明 PID 都不存在时仍提醒。只凭耗时或日志一段时间没变化，不能判断任务卡住。
- 刷新或动画异常写入插件 debug 日志，不弹给用户。运行记录暂时读取失败时保留已有有效状态，读取错误也记入 debug 日志。
- 面板显示时，`flow/statusline.mjs`（ccstatusline 调用）不画 codex 那一行，根据 mod 写入的 `~/.claude/codex-flow/panel-<会话>.json` 判断。
- 没加载 mod 时，后台 Bash 仍给完成通知；可后台跑 `codex-flow.mjs watch <runId> --alert-after <秒>` 获取提前提醒。

改 mod 后运行 `command claude plugin validate mod` 和 `command claude plugin test mod`；改执行器后运行 `node --test flow/tests/`。
